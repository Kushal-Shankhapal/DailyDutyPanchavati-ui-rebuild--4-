# Session Handoff Procedure
1. docs/CURRENT_STATE.md: update implementation truth + verification status + Session log row (date, change, verified-by).
2. docs/OPEN_QUESTIONS.md: add ambiguities discovered; close any the evidence settled (say how).
3. docs/TRACEABILITY.md: move rows with real verification.
4. changes/<id>/proposal.md: active work units updated or closed.
5. Next step: one sentence at the end of CURRENT_STATE ("Next step (unblocked): ...").
Keep it compact; the next session must be able to resume from these files alone.
